# バイトシフト確認

カレンダーにバイトの開始・終了時間を入力するだけのシフト確認アプリです。休みの日は自動で色分けされ、時給を登録すれば給与も自動計算されます。

- `index.html` … 紹介ページ(ランディングページ)
- `app/index.html` … アプリ本体(単一HTMLファイル、ビルド不要)

## 主な機能

- カレンダーへのシフト(開始・終了時間)登録
- シフトあり(青)/ 休み(赤)の自動色分け
- 月表示 / 週表示の切り替え
- 音声入力での時間登録
- 時給登録による給与自動計算
- データはブラウザの localStorage に保存(サーバー送信なし)
